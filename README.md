# Estante & Diário de Leitura

Aplicação desktop em **Java** com interface gráfica **Swing** e persistência local em **SQLite** via **JDBC**, gerenciada com **Maven**.

## Funcionalidades
- Cadastro, edição e exclusão de livros.
- Busca por título ou autor e filtro por status (*Quero ler*, *Lendo*, *Concluído*).
- Registro de avaliação (1 a 5) e resenhas por livro.
- Criação automática da tabela no banco SQLite na primeira execução.

## Tecnologias
- Java
- Maven
- Java Swing
- SQLite (`sqlite-jdbc`)
